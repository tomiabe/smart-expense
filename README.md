# Smart Expense Agent

AI-powered expense detection and tracking — describe a purchase or scan a receipt and the agent categorises and logs it for you.

**Live:** [smart-expense-omega.vercel.app](https://smart-expense-omega.vercel.app)

**Features**

- Natural-language expense entry ("coffee with a client, £12")
- AI auto-categorisation of spending
- Clean dashboard with dark mode support

## Tech Stack

- Next.js 14 (App Router), TypeScript
- Tailwind CSS + shadcn/ui
- AI expense detection (Gemini)

## Run Locally

**Prerequisites:** Node.js 18+

```bash
npm install
npm run dev
```
